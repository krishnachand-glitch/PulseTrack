---

## 📸 Screenshots

### Dashboard
The main dashboard features real-time health metrics, animated activity goal rings, interactive heart rate charts, weekly step tracking, and recent activity feed.

### Route Map
Interactive map powered by Leaflet showing workout routes with start/end markers, per-km splits, and detailed route statistics.

### Statistics
Deep analytics with monthly step trends, calorie breakdowns, sleep patterns, and workout distribution charts.

## ✨ Features

### 📊 Dashboard
- **Live Heart Rate Monitor** — Simulated real-time heart rate with animated display
- **Health Metric Cards** — Steps, Calories, Sleep Duration with trends & progress bars
- **Activity Goal Rings** — Animated SVG rings tracking Move, Exercise & Stand goals
- **Heart Rate Chart** — Interactive line chart with Day / Week / Month toggle
- **Weekly Steps Chart** — Color-coded bar chart (green = goal met)
- **Recent Activities Feed** — Quick view of latest workouts

### 🏃 Activities
- **Full Activity Log** — Table of all workouts with type, date, duration, distance, calories & heart rate
- **Filter by Type** — Running, Cycling, Swimming, Yoga, Gym
- **Add New Activity** — Modal form to log custom workouts in real-time
- **Monthly Stats Summary** — Total activities, distance, time & calories

### 🗺️ Route Map
- **Interactive Leaflet Map** — OpenStreetMap tiles with zoom controls
- **3 Workout Routes** — Morning Run, Evening Cycle, Weekend Hike
- **Route Stats Panel** — Distance, duration, pace, avg HR, elevation, calories
- **Per-Km Splits** — Detailed split times for each kilometer
- **Start/End Markers** — Color-coded markers on the map

### 📈 Statistics
- **Monthly Steps Trend** — Line chart tracking yearly progress
- **Calorie Breakdown** — Stacked bar chart (active vs resting)
- **Sleep Pattern Analysis** — Deep sleep vs total sleep over 7 nights
- **Workout Distribution** — Doughnut chart of activity types
- **Performance Metrics** — Resting HR, VO2 Max, Avg Pace, Active Days, Streak

### 👤 Profile
- **User Information** — Personal health data (age, height, weight, blood type)
- **Daily Goals** — Progress bars for steps, calories, sleep & water intake
- **Achievements** — Unlockable badges (First 5K, 7-Day Streak, Step Master, etc.)

## 🚀 Getting Started

### Quick Start
No installation, no build tools, no dependencies to install. Just:

1. **Clone the repository**
   ```bash
   git clone https://github.com/krishnachand-glitch/PulseTrack.git
   ```

2. **Open `index.html` in your browser**
   ```bash
   cd PulseTrack
   start index.html        # Windows
   open index.html          # macOS
   xdg-open index.html      # Linux
   ```

3. **That's it!** 🎉

> **Note:** An internet connection is required on first load for CDN resources (Tailwind CSS, Chart.js, Leaflet, fonts, icons).

## 🎨 Design Highlights

- 🎯 **Clean & Modern UI** — Inspired by Apple Health and Strava
- ✨ **Smooth Animations** — Fade-in views, counter animations, ring progress, hover effects
- 📱 **Responsive Layout** — Sidebar collapses on smaller screens
